# IMAGE SIMILARITY AND RECOMMENDATION SYSTEM

## 🔎Overview:
This project is focused on building a machine learning model that recommends visually similar 'k' number of images based on the query image uploaded by the user using the extracted feature embeddings.A pre-trained Convolutional Neural Network (CNN) model ResNet50 is used as a feature extractor.he project includes all essential steps of the machine learning pipeline — from dataset loading to model evaluation and recommendation.

The model is trained on an image dataset named 'Caltech 101' with 101 classes having 40-800 images approximately.Feature extraction is done at first using the pre-trained CNN model and Cosine Similarity comparision using distance metrics is used to recommend images based on the query image.

📌Language: Python<br>
💻Environment: Jupyter Notebook<br>
📝Model/Algorithm Used: Pre-trained Convolutional Neural Network (CNN) using ResNet50 model,Similarity Matching using Cosine Similarity<br>
📚Libraries: tensorflow / keras,numpy,scikit-learn,matplotlib,Pillow (PIL),os,pickle,faiss

## 📊Dataset
The model is trained on the dataset "https://www.kaggle.com/datasets/imbikramsaha/caltech-101" with:<br>
•Format: .jpg<br>
•Labels: 101 classes with number of images ranging from 40-800<br>
•Resolution: 300x200

## 🧩Features:
1. 🖼️ Image Preprocessing Pipeline<br>
  • Automatic loading of images from the dataset directories<br>
  • Resizing images to a fixed input size (e.g., 224 × 224)<br>
  • Normalization of pixel values<br>
  • Conversion of images into numerical arrays suitable for CNN input<br>

2. 🧠 Deep Feature Extraction using CNN<br>
 • Uses a pre-trained Convolutional Neural Network (CNN) named ResNet50 with ImageNet weights<br>
 • Final classification layer removed to act as a feature extractor<br>
 • Extracts high-level visual feature embeddings from images<br>
 • Enables semantic understanding of image content<br>

3. 📦 Feature Vector Storage<br>
 • Extracted feature vectors are stored using pickle<br>
 • Corresponding image file paths are saved for efficient retrieval<br>
 • Avoids recomputation of features during recommendation<br>

4. 🔍 Similarity-Based Image Recommendation<br>
 • Computes similarity between images using Cosine Similarity<br>
 • Identifies top-N visually similar images for a given query image<br>
 • Implements content-based image retrieval (no labels required)<br>

5. 📊 Visualization of Recommendations<br>
 • Displays the query image<br>
 • Shows recommended similar images using matplotlib<br>
 • Helps visually validate the recommendation results<br>

 ## 🌲Model Training:<br>
 • I have used GPU(NVIDIA CUDA) for this project<br>
 • No model training is performed in this project<br>
 • A pre-trained Convolutional Neural Network (CNN) (trained on ImageNet) is used<br>
 • The CNN is used only as a feature extractor, not for classification<br>
 • The final fully connected (classification) layers are removed<br>
 • All images are passed through the CNN to extract feature embeddings<br>
 • No train–test split is required, as the task is image similarity retrieval, not supervised learning<br>
 • Image features are computed once and stored for reuse<br>
 • Recommendations are generated by comparing feature vectors using cosine similarity<br>

  ## 📈Evaluation Metrics:<br>
  • Accuracy(Top-1,Top-k)<br>
  • Precision<br>
  • Recall<br>
