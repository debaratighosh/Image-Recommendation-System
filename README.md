# IMAGE SIMILARITY AND RECOMMENDATION SYSTEM

## 🔎Overview:
This project is focused on building a machine learning model that recommends visually similar 'k' number of images based on the query image uploaded by the user using the extracted feature embeddings.A pre-trained Convolutional Neural Network (CNN) model ResNet50 is used as a feature extractor.he project includes all essential steps of the machine learning pipeline — from dataset loading to model evaluation and recommendation.
